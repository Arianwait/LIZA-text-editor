# Liza Text Editor — визуальный редактор сценариев

Десктопный редактор для визуальной новеллы на движке **Liza**. Позволяет собирать
сюжет в виде графа сцен, редактировать реплики, персонажей, главы и команды через
интерфейс и сохранять всё в XML-формат, который читает движок
(`Dialog_Structured.xml`, `Person.xml`, `Chapters.xml`).

> Точка входа — `kz.arianwait.gametexteditor.EditorApp`. Окно без системной рамки, со своей
> титульной панелью и тёмной темой.

---

## ✨ Возможности

- 🗺 **Граф сцен** — визуальная карта сцен и переходов (узлы + связи) с автораскладкой
- 🌳 **Дерево проекта** с фильтром по сценам
- 💬 **Редактор кадров/реплик** — текст, говорящий, цвет, выборы и ветвления
- 👤 **Редактор персонажей** — имена, позы, цвета
- 📚 **Редактор глав**
- 🎛 **Палитра команд** — вставка команд движка (эффекты, показ персонажей, смена фона, панели и т.д.)
- 🖼 **Менеджер ресурсов** — выбор и импорт картинок и звуков из проекта
- 👁 **Мини-превью** кадра
- ✅ **Валидация проекта** — поиск ошибок (битые переходы, недостающие ресурсы)
- 🔎 **Поиск** по сценам и репликам
- ↩️ **Undo/Redo**, история навигации, отслеживание несохранённых изменений
- 📋 **Копирование/вставка кадров** и шаблоны кадров
- 🕘 **Недавние проекты**
- ⌨️ **Горячие клавиши**
- 🔄 **Импорт/экспорт** в XML-формат движка Liza

| Компонент | Версия |
|-----------|--------|
| JDK       | 21     |
| Maven     | 3.8+   |
| JavaFX    | 21.0.5 (тянется Maven'ом автоматически) |

Единственная внешняя зависимость — `javafx-controls`.

---

## Запуск

### Вариант 1. Из Maven (для разработки)

```bash
mvn clean javafx:run
```

### Вариант 2. «Толстый» JAR (со всеми зависимостями)

```bash
mvn clean package
java -jar target/kz.arianwait.gametexteditor-0.0.1-SNAPSHOT-jar-with-dependencies.jar
```

### Вариант 3. Готовый `.exe` (Windows)

`mvn package` через **launch4j** дополнительно собирает `target/LizaTextEditor.exe`
(ожидает рядом JRE 17+ в папке `jre`).

## Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl+S` | Сохранить |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Отменить / Повторить |
| `Ctrl+N` | Новый кадр |
| `Ctrl+C` / `Ctrl+V` | Копировать / Вставить кадр (в режиме редактора) |
| `Ctrl+Shift+V` | Проверить (валидация) проект |
| `Ctrl+F` | Поиск |
| `Ctrl+T` | Переключить тип кадра (в режиме редактора) |
| `Alt+←` / `Alt+→` | Назад / Вперёд по истории навигации |
| `Delete` | Удалить выбранное |
| `Esc` | Закрыть редактор кадра |

В полях ввода стандартные сочетания (копирование/вставка/выделение) работают как обычно.

## Структура проекта

```
src/main/java/kz/arianwait/gametexteditor/
├── EditorApp.java          — точка входа (JavaFX Application)
├── controller/             — MainController: главное окно, меню, общий рабочий процесс
├── model/                  — модель данных проекта (EditorProject, EditorScene,
│                             EditorFrame, EditorCharacter, EditorChapter, EditorCommand …)
├── graph/                  — граф сцен (GraphPane, SceneNode, EdgeLine, GraphLayoutEngine)
├── tree/                   — дерево структуры проекта (SceneTreeBuilder, SceneTreeCell)
├── editor/                 — панели редактирования (диалоги, персонажи, главы, кадры, выборы)
├── palette/                — палитра команд, менеджер и пикеры ресурсов
├── parser/                 — чтение XML движка (Dialog/Person/Chapters/Buttons/Themes)
├── writer/                 — запись XML движка (Dialog/Person/Chapters)
├── io/                     — SceneExporter (экспорт проекта)
├── project/                — мастер нового проекта и загрузчик
├── preview/                — мини-превью кадра
├── search/                 — поиск по проекту
├── validation/             — валидатор проекта и окно результатов
├── cache/                  — отслеживание изменений (DirtyTracker, EditorCache)
├── util/                   — undo/redo, горячие клавиши, недавние проекты, шаблоны,
│                             импорт ресурсов, статистика текста, CSS
└── window/                 — кастомная титульная панель и перетаскивание окна

src/main/resources/kz/arianwait/gametexteditor/css/editor-dark.css   — тёмная тема
```

## Рабочий процесс

1. **Создай или открой проект** — мастер нового проекта или открытие папки игры на движке
   Liza (той, где лежит `lib/Scene/Dialog_Structured.xml`).
2. **Редактируй** — собирай сцены в графе, правь реплики, персонажей и главы,
   вставляй команды движка из палитры, подключай ресурсы.
3. **Проверяй** — валидация находит битые переходы и недостающие ресурсы (`Ctrl+Shift+V`).
4. **Сохраняй** (`Ctrl+S`) — редактор пишет XML обратно в формат движка, и игру можно
   сразу запускать в Liza.

---

## Где хранятся данные

- **Контент игры** редактируется прямо в папке проекта движка (`lib/...`), а не внутри
  этого репозитория.
- **Личные данные** (список недавних проектов, шаблоны кадров) хранятся в домашней папке
  пользователя — `~/.liza-editor/` — и в репозиторий не попадают.
